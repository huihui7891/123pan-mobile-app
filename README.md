## 功能特性

### 文件管理
- 文件列表浏览，单击文件夹进入，长按弹出操作菜单
- 文件夹操作：打开、下载、分享、详细信息、移动、复制、重命名、删除
- 文件操作：播放/预览、下载、分享、详细信息、移动、复制、重命名、删除
- 多选批量操作（整理模式）：批量移动、批量复制、批量删除
- 文件类型图标按类型着色（文件夹/图片/视频/音频/文档/APK等）
- 文件列表滚动分页加载，顶部下拉刷新
- 排序（按文件名/大小/修改时间）

### 上传下载
- 上传文件 / 文件夹（保留目录结构）
- 单文件下载、文件夹批量打包下载（自动加 .zip 后缀）
- 下载进度显示，传输记录管理
- 上传/下载时自动保持屏幕常亮
- 自定义下载缓存目录

### 预览
- 图片/视频/音频在线播放
- 文本文件查看
- PDF/Word/Excel 预览
- HTML 文件网页预览（支持网页/源码切换）

### 其他
- 日间/夜间/跟随系统主题
- 回收站（恢复/彻底删除）
- 一键查重（文件名+大小判重）
- 离线下载（磁力/HTTP 链接）
- 多账号管理
- 分享管理
